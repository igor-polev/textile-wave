## Textile-Wave

A simple simulation of textile dynamics for the test of XPBD modeling method.

## Dependancies

npm install is only needed for editor type hints; to run, serve the folder over HTTP and open index.html in Chrome.

## Math involved

- [XPBD](https://matthias-research.github.io/pages/publications/XPBD.pdf);
- [Small Steps modification of XPBD](https://matthias-research.github.io/pages/publications/smallsteps.pdf).
